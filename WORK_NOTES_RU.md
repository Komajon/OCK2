- Нижняя навигация теперь подсвечивает активный раздел.
- Обновлён главный экран: более выразительный заголовок, блок состояния среды и более ясные подписи.

## Что ещё НЕ реализовано
- Ubuntu ARM64 rootfs и PRoot пока не добавлены.
- Терминал пока запускает Android `/system/bin/sh`, а не Ubuntu Bash.
- Интерактивный PTY пока не реализован.
- APK в этой среде не собран: в архиве нет Gradle Wrapper, а локальная среда не содержит установленного Gradle/Android SDK.

## Следующий этап

2. Сделать первичную установку с прогрессом, проверкой места и возможностью повторить после ошибки.
3. Переключить терминал на PRoot/Bash и реализовать PTY.
4. Добавить экран Linux-среды: установка, запуск, остановка, состояние и размер rootfs.
5. Собрать APK через GitHub Actions и проверить установку на устройстве.

## Ubuntu ARM64 / PRoot — добавлено в исходники

- Добавлен `ProotEnvironment.kt`: загрузка Android ARM64 PRoot и официального Ubuntu Base 24.04.5 ARM64, распаковка во внутреннюю память приложения, подготовка DNS и запуск bash.
- Добавлена вкладка «Ubuntu» и кнопка установки на главном экране.
- После установки терминал запускает Ubuntu bash вместо Android `/system/bin/sh`.
- Добавлены быстрые действия `apt update` и установка Python 3.
- Среда не требует root-доступа; это PRoot, поэтому systemd и функции ядра Linux не обещаются.

Важно: APK пока не собран в этой среде (здесь отсутствует Gradle/Android SDK). Установка и запуск на физическом Android-устройстве ещё требуют проверки. Первый запуск требует интернет и свободное место для распаковки rootfs (значительно больше 30 МБ).
